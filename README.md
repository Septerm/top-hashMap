# top-hashMap


A Simple project where a HashMap data strucute was created as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum. The project contains a HashMap class.


### Prerequisites

- [Node.js](https://nodejs.org/) and npm installed on your machine.

### Installation

```bash
# Clone the repository
git clone https://github.com/Septerm/top-hashMap.git

# Navigate into the project
cd top-hashMap

# Install dependencies
npm install

# Running test script 

node hashMapjs

```
